# TaskFlow AI - AI Operations Management Platform

TaskFlow AI is a modern, full-stack project and task management platform designed specifically for AI Operations workflows.

FEATURES:
- Role-Based Access Control (Admin/Member)
- Dynamic Dashboard with Analytics
- Project Management Pipelines
- Kanban Board with Drag-and-Drop
- Real-time Notifications
- Activity Logs (Audit Trail)

TECH STACK:
- Frontend: React.js, Tailwind CSS, Framer Motion, Recharts
- Backend: Node.js, Express.js, JWT Auth
- Database: MongoDB

INSTALLATION:
1. Backend: cd backend && npm install && npm run server
2. Frontend: cd frontend && npm install && npm run dev
